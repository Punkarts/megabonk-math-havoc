# Début du code source
core/BonusRules.cs contient le calcul pur des gains et de la division du total par deux. Le paramètre gainPerAnswer doit venir de design/systems.json (0,01).
Le projet .NET Standard 2.0 est un candidat indépendant du loader. Il n'a pas été compilé ici : aucun SDK dotnet disponible.
Aucune pause, collecte, session Havoc, application des dégâts ou installation de mod n'est implémentée.
Le reste de [l'architecture](../docs/ARCHITECTURE.md) exige l'inspection des copies Windows.
